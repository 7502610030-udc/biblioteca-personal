# Proyecto: Biblioteca Personal

## Integrantes y Roles
* **[Raul Jaramillo 7502610030]** - Líder de Proyecto / Desarrollador de Software

## Funcionalidades
El sistema es una aplicación de consola en Java que permitegestionar una biblioteca personal con las siguientes opciones:
1. Registrar un libro en la lista.
2. Buscar un libro por su título (sin importar mayúsculas/minúsculas).
3. Contar la cantidad total de libros registrados.
4. Listar todos los libros almacenados en orden numérico.
5. Salir del programa de forma limpia.

## Instrucciones de Ejecución
1. Abrir el proyecto en Visual Studio Code.
2. Asegurarse de tener instalado el Java Extension Pack.
3. Abrir el archivo ´Main.java´.
4. Presionar ´Ctrl + F5´ o el botón de Play superior derecho para iniciar la consola interactiva.

## Evidencias del Flujo Colaborativo
El proyecto se desarrolló utilizando Git y GitHub bajo la metodología de GitFlow, creando ramas independientes (´features/...´) para cada módulo solicitado y uniendo el código a la rama principal ´main´ mediante la aprobación de Pull Request.
